- Built a fully local, privacy-first RAG chatbot where PDFs, embeddings, chat history, and LLM inference never leave the user’s machine.  
- Implemented hybrid retrieval (semantic similarity + MMR + BM25) for high-quality, grounded answers with exact source attribution (filename + page number).  
- Designed a monorepo architecture with Next.js 16 frontend and FastAPI backend, fully orchestrated via Docker Compose (including local Ollama). Also supports local development without Docker using pnpm concurrently.  
- Added persistent chat sessions using SQLite and a polished dark glassmorphism UI with real-time health monitoring.  
- Enabled one-command setup for the entire stack (frontend + backend + vector DB + local LLM).
